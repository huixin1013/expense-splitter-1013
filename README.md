# Friend Expense Splitter

A smart expense-splitting and debt-tracking application with real-time multi-user synchronization, currency conversion, and Excel integration.

---

## Key Features & Functions

### 1. Expense Tracking
- **Add Expenses:** Record shared or personal expenses with custom categories, amounts, currencies, and dates.
- **Flexible Splitting:** Split costs equally across all members or select specific individuals/subgroups.
- **Edit & Delete:** Modify details or remove existing expense entries anytime.

### 2. Balances & Debt Settlement
- **Live Net Balances:** Instantly see how much you are owed or owe to each friend.
- **Settle Up Payments:** Log partial or complete debt repayments between members with payment history.
- **Smart Debt Simplification:** Automatically calculates optimal payment paths between members.

### 3. Multi-Currency Support
- **Multi-Currency Entry:** Enter expenses in any international currency (SGD, MYR, USD, EUR, JPY, GBP, etc.).
- **Live Exchange Rates:** Fetch real-time exchange rates with automatic conversion to your preferred display currency.
- **Interactive Currency Converter:** Quickly convert and calculate amounts between currencies on the fly.

### 4. Multi-User & Profile Management
- **Switch Active User:** Switch between member profiles to view personalized finances and debt summaries.
- **PIN / Password Verification:** Secure profile switching using user PINs.
- **Team Management (Developer):** Add new members, edit member names, or remove members.

### 5. Excel Database & Templates
- **Download Current Data:** Export full expense and settlement records into a 1:1 structured `.xlsx` spreadsheet.
- **Download Template:** Generate a clean data entry template with built-in validation formulas and dropdowns.
- **Upload Template / Excel:** Upload `.xlsx` spreadsheets to instantly batch-import expenses and settlements.
- **Download users.xlsx (Developer):** Export team member credentials and roles into a dedicated credentials workbook.

### 6. Sharing & Filters
- **Share Spending Summary:** Copy a formatted summary of balances and recent records for WhatsApp, Telegram, or SMS.
- **Date Range Filters:** Filter expenses by All Time, This Month, Last Month, or custom date ranges.
- **Category Breakdown:** View spending totals grouped by categories (Dining, Groceries, Transport, Bills, etc.).
- **Clear All Data (Developer):** Securely wipe all transaction records from the cloud database and backup file.
